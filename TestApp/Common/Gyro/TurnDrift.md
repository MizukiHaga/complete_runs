# 左右別の補正ウェイト

TurnDrift.hのEncoderWeightLeft（左旋回）、EncoderWeightRight（右旋回）をそれぞれ0〜1で設定する。
分割時は両方とも既存値0.293を引き継いでいる。
旋回指令directionが負なら左、正なら右を選び、実測車輪角の符号には手を加えない。
旋回中のestimateと旋回後のupdateは同じ重みを使用する。既存DRIFT_gainログで選択値を確認できる。

# 現在の車輪角の計算

左右のエンコーダは前進正の符号を維持し、次の式で車体角を求める。

```text
エンコーダ旋回角 = (左回転量 − 右回転量) / 2 × 90 / EncoderPer90Deg
補正量 = EncoderWeightLeft/EncoderWeightRight × (エンコーダ旋回角 − ジャイロ旋回角)
```

指定旋回方向で符号を付け直さない。両輪の共通の前後移動は差で相殺する。
例: 左+180/右-180は右90度、左-180/右+180は左90度、両輪+180は0度。
左右差・方向による自動無効化は追加しない。重みは今回変更しない。
以下の復元時点の説明のうち、絶対値平均から求める旧換算の記述はこの説明へ置き換える。

# 現在の変更: 自動的な補正無効化を撤去

左右差、逆方向判定、開始時の小回転による補正の抑止と、旋回終了まで無効にするラッチを撤去した。
設定はEnabled・EncoderPer90Deg・EncoderWeightLeft/EncoderWeightRight・SettleMsのみ。
エンコーダ取得成功・有限な角度・有効な方向指定では、開始直後から同じ重みで補正を計算する。
取得失敗・NaN等の周期だけ補正を0とし、次の正常サンプルで再開する。
開始エンコーダを取得できなかった場合は累積量の基準がないため、その旋回の補正は計算できない。
最終補正の一度だけの適用は維持する。今回、符号や車輪角の換算式は変更していない。

以下は復元時点の説明であり、補正除外条件に関する記述は上記の変更を優先する。

# 旋回中の固定比率融合

両輪逆回転のその場旋回で使用する。Nansho3とTestのIMU旋回で共有。
エンコーダのみの旋回や、融合を無効にした呼び出しには適用しない。

1. 開始時に補正済み方位H0、生ジャイロ、左右エンコーダを保存する。
2. 毎周期、生ジャイロの差を±180°に折り返して累積しθgとする。
3. 左右エンコーダ増分の絶対値平均をEとし、θe = 方向 × E × 90 / EncoderPer90Deg。
4. θf = (1-w)θg + wθe。wはEncoderWeightLeft/EncoderWeightRight（初期値0.2）。
5. 計画旋回角needに対し、残りneed - 方向 × θfで低速化・手前停止を判断する。
6. 停止後SettleMs（80ms）も計測する。
7. 最終方位H0 + θfと現在の補正済み方位の差を一度だけ反映する。
8. 追い旋回せず、元の絶対目標方位で直進する。

融合値をジャイロ積分へフィードバックしない。周期ごとの補正を累積しない。
180°到達サンプル条件、標準偏差による重み計算、追い旋回、到達音は廃止。
最初の平均車輪角20°未満は量子化を避けるためジャイロのみ。
車輪角取得失敗・非有限値は即座にその旋回の融合を無効にする。
左右差は平均20°以上、絶対差4°超、差率35%超のすべてを満たす場合に確認する。
開始基準から車輪の逆方向4°以内、ジャイロの逆方向2°以内の揺れは許容する。
大きな逆方向移動は暖機中も確認する。
左右不一致または逆方向の同じ異常が実時間20ms継続したら、
その旋回の残りはジャイロのみに切り替える。
確認中はジャイロのみだが、正常復帰すれば融合へ戻り、確認時間もリセットする。
両輪が同時に空転する場合の検出はできない。

DRIFT_gainは現在の固定比率（異常・開始直後は0）、DRIFT_corrは最終適用量。
DRIFT_errはθe−θg、DRIFT_remはそのうち融合で反映しなかった差。
これらは実際の目標角からの誤差ではない。診断カウンタは各周期の評価回数。
STOPログは停止指令直前、通常の旋回ログは静定後。
