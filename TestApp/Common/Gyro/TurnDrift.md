# 旋回中の固定比率融合（比較用）

現在は `HeadingFusionSettings.h` の連続推定が既定。
この処理は `Enabled=false` の比較時だけ使用する。
設定・校正・KFログは [HeadingFusion.md](HeadingFusion.md) を参照。

Nansho3とTestのIMU旋回で共有する。エンコーダのみの旋回や、融合を無効にした
呼び出しには適用しない。追い旋回は行わない。

## 入力と符号

ジャイロ角・車体の旋回角はCW正。左右車輪はどちらも前進正。
`estimate()` / `update()`へ渡すl/rは、旋回開始からの**符号付き**回転量。
絶対値化しない。現在のモータ設定とtachoの正方向に対応している。

```text
E = (左車輪角 − 右車輪角) / 2
エンコーダ旋回角 θe = E × 90 / EncoderPer90Deg
補正 C = EncoderWeight × (θe − 生ジャイロ累積角 θg)
融合旋回角 θf = θg + C
```

| 動き | 左車輪 | 右車輪 | θeの符号 |
|---|---:|---:|---|
| 右旋回 | + | − | + |
| 左旋回 | − | + | − |
| 同量の前進・後退 | 同値 | 同値 | 0 |

両輪へ同じ移動量を加えても差は変わらない。左右の移動差や車輪の滑りまでは
自動で除去できないため、EncoderPer90Degは実機で校正する。

## 補正の適用

1. 開始時に補正済み方位H0、生ジャイロ、左右エンコーダを保存する。
2. 毎周期、生ジャイロの周期差を±180度へ折り返し、θgへ積算する。
3. 符号付き車輪差からθeを求め、固定比率で融合する。
4. 目標までの残り角をθfから判断し、低速化・手前停止する。
5. 停止後SettleMs（80ms）も計測する。
6. 最終方位H0+θfと現在の補正済み方位との差を一度だけ反映する。
7. 元の絶対目標方位を直進の目標に使う。追い旋回は行わない。

**エンコーダ角が小さい側も同じ重みで補正する。** 片側だけ補正0にすると
測定誤差の平均が偏るため、以前のEncoderUnderReadによる採否は廃止した。
DRIFT_underは小さい側だったサンプル数として残すが、補正を止める条件ではない。
起動時、左右差、逆方向、継続時間による補正停止や、無効状態の保持も行わない。

取得失敗・非有限値・方向指定値が±1以外の場合は、そのサンプルだけ補正0。
次の正常サンプルで復帰する。開始基準を取得できなかった場合は、累積値を計算できない。
方向引数は互換性のため残すが、エンコーダ角の符号は実測の左右差で決める。
既存APIのsample_ms・direction_valid・elapsedは採否には使わない。

EncoderWeight（現在0.268）は閾値ではなく融合の重み。上げるほどエンコーダ換算の
誤差も強く反映されるため、車輪角を校正してから調整する。
融合値をジャイロ積分へフィードバックせず、同じ旋回内の補正を周期ごとに累積しない。
1D/3D切替時は補正済み方位を連続に保つ。

## 旋回方向

絶対目標へは180度以内の最短旋回を行う。prefer_signは±180度で同距離の場合だけ使う。
従来の「45度未満なら逆方向、45度以上なら指定方向へ大回り」という分岐は廃止した。
例えば目標差−44.9度も−45.1度も左へ回り、314.9度の右旋回へ切り替わらない。

## ログ

Nansho3.hのEnableTurnLog=trueにし、BLE端末を接続してから起動する。

| 項目 | 意味 |
|---|---|
| DIR | 実測した本旋回の方向。予定方向ではない |
| DRIFT_Lsigned / DRIFT_Rsigned | 前進正の符号付き車輪角 |
| DRIFT_enc_signed | 左右差から算出したCW正の旋回角θe |
| DRIFT_gyro_signed | CW正の生ジャイロ累積角θg |
| DRIFT_gain | 固定比率。計算不能サンプルのみ0 |
| DRIFT_err / DRIFT_rem | θe−θg / 補正後に残る差 |
| DRIFT_corr | 最終的に適用した補正量 |
| DRIFT_under | エンコーダ角の絶対値がジャイロ角より小さかった回数。診断専用 |

既存のENC_angは互換性のため絶対値平均を維持している。補正の検証には
DRIFT_enc_signedを使う。状態番号9は旧EncoderUnderReadとして予約し、現在は返さない。
STOPログは停止指令直前、通常の旋回ログは静定後。実角は外部計測していない。

workspaceから実行する。

```sh
g++ -std=c++11 -Wall -Wextra -Werror TestApp/tests/turn_drift_test.cpp -o /tmp/turn_drift_test
/tmp/turn_drift_test
python3 TestApp/tests/turn_direction_test.py
make img=TestApp
```

左右符号、過大・過小の対称性、前後並進の除去、最終補正の一度だけの適用、
旧45度境界と±180度の方向選択を検証する。実機の校正誤差・滑りは数値試験に含まない。
