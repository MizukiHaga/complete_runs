# Nansho3 の直進停止調整

停止する直進は、総距離の中でS字減速し、エンコーダが目標値に達した時点で
`Straight::brake()`の短絡ブレーキへ切り替える。惰性停止は使用しない。
ブレーキ後は `CoreStraightBrakeSettleMs` 待ってから後続動作へ進む。
停止しない連続直進の途中マスにはブレーキを掛けない。

調整箇所は `Nansho3.h`。

| 定数 | 基準・調整方法 |
|---|---|
| `CoreStraightDegL` / `R` | 減速を含めた停止する1マスの総距離。現在505度 |
| `CoreStraightContinueDegL` / `R` | 停止しない途中マスの距離。現在505度 |
| `CoreStraightDecelDeg` | 総距離のうち減速に使う距離。現在150度。増やすと早く減速する |
| `CoreStraightDecelMinPower` | 減速終端の駆動パワー。現在40。下げると速度を落とせるが、目標前で停滞しない範囲にする |
| `CoreStraightBrakeSettleMs` | ブレーキ後の待ち。現在100ms。停止位置の手前でブレーキを掛ける設定ではない |
| `InitialStraightDeg` | 初期直進の総距離。現在610度 |
| `InitialStraightDecelDeg` | 初期直進の減速距離。現在100度 |

通常の1マスは、始点から355度まで走行し、505度までの残り150度で減速する。
505度にさらに減速距離を追加する処理ではない。
最低パワー40で到達してからブレーキを掛けるため、実機の停止距離が完全に0になるわけではない。

まず1マスと3マス連続の停止位置を比較する。連続時だけ行き過ぎる場合は、
総距離をすぐに短くせず `CoreStraightDecelDeg` を増やして終端速度を落とす。
必要なら最低パワーを少しずつ下げ、停滞しないことを確認する。
待ち時間だけを増やしても、目標到達時の速度は下がらない。
短絡ブレーキによる車体の揺れ・滑りも実機で確認する。

初期直進や青検知後の直進など、`decelToStopByEncoder()`を共用する処理にも
同じ停止方法が適用される。Nansho3KYOKUの初期動作もこの処理を共用する。
他シーンの `stop()` / `coast()` の挙動は変更していない。

検証は `python3 tests/nansho3_brake_test.py`。
実ソースの減速処理を抽出し、簡易モデルで距離判定・ブレーキ・停止待ち・停滞時の抜けを確認する。
実機の停止距離を保証する試験ではない。

## 旋回ログ

追い旋回は行わない。既定では連続KFの推定角で旋回を終了して直進へ進む。
連続推定の設定・校正手順は `../../Common/Gyro/HeadingFusion.md` を参照。
ログを出す場合はNansho3.hのEnableTurnLog=trueにしてBLE端末を接続する。
連続推定有効時はKF_bias、KF_noise、KF_count等を出力する。
連続推定を無効にした比較時だけ従来のDRIFTログを出力する。
